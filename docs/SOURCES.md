# 資料源決策紀錄（SOURCES.md）

每個價格來源「為什麼採用 / 為什麼不採用 / 什麼狀況會抓不到」的單一真相來源。
新增或更換來源時，請同步更新本檔與 `app/sources.py`、`app/config.py`。

格式：每個來源記錄 採用狀態、理由、實作位置、已知失敗情形、抓不到時的行為。

---

## ✅ 採用中

### 大陸期貨（上期所 / 大商所）— akshare
- **採用標的**：滬金、滬銀、滬銅、滬鎳、螺紋鋼、鐵礦石（主力合約，RMB）
- **實作**：`app/sources.py: fetch_cn()`，呼叫 `akshare.futures_zh_realtime(symbol=中文品種名)`，取持倉量最大者
- **為何採用**：免費、免金鑰、覆蓋大陸全金屬；對大陸用戶最直覺
- **已知失敗情形**：
  - akshare 介面/欄位偶爾改版 → 函式名或回傳欄位對不上
  - 中文品種名不符（如「沪铜」vs「铜」）→ 查無資料
  - **從 GitHub Actions（境外 runner）抓新浪/東財偶爾逾時或被限速**
- **抓不到時的行為**：`fetch_cn` 已內建重試 3 次；仍失敗則該格回 `ok=False`，訊息顯示「—（錯誤）」，不影響其他金屬；下次排程通常會補上
- **修復指引**：先 `pip install -U akshare`，再對照 https://akshare.akfamily.xyz 確認函式與品種名

### 美國 COMEX — yfinance
- **採用標的**：黃金 GC=F、白銀 SI=F、銅 HG=F（連續期貨，USD）
- **實作**：`app/sources.py: fetch_comex()`
- **為何採用**：ticker 穩定、免費、可靠；國際基準價
- **已知失敗情形**：Yahoo 偶發空資料 / 限流；ticker 變更（極少）
- **抓不到時的行為**：該格回 `ok=False`，其餘照常

### 倫敦 LME（鎳）— 新浪外盤
- **採用標的**：LME 鎳 `hf_NID`（USD）
- **實作**：`app/sources.py: fetch_lme()`，`hq.sinajs.cn/list=hf_NID`，需帶 `Referer`
- **為何採用**：鎳的國際盤在倫敦不在美國；新浪外盤免費可取
- **已知失敗情形**：
  - 新浪欄位順序偶爾調整 → last/漲跌索引位移（程式已對漲跌做 try/except 容錯）
  - 端點臨時不穩 / Referer 被擋
- **抓不到時的行為**：該格回 `ok=False`，其餘照常
- **備註**：欄位若位移，`print(parts)` 看索引後調整 `fetch_lme` 內的 `parts[0]/parts[7]`

## ❌ 不採用

### 台灣（台期所 TAIFEX）
- **狀態**：**不提供台灣數據**
- **理由**：
  1. 台期所金屬期貨**只有黃金**一項，銅/銀/鎳/鐵皆無
  2. 台期所**沒有官方的免費即時 API**；可得來源多為延遲、需爬官網頁面解析，可靠度與時效不足
  3. 曾評估「以國際金價×匯率換算台幣」當替代，但**那是估算、非官方數據**，與「只提供可靠官方數據」原則相違，故移除
- **重新採用的條件**：台期所提供官方即時行情介面，或找到具公信力的官方授權即時源

### 美國「鎳」
- **狀態**：不提供
- **理由**：美國（COMEX/CME）無流動的鎳期貨；鎳的國際盤在 LME（倫敦），已由 LME 來源涵蓋

### 美國「鐵 / 鋼」
- **狀態**：暫不提供
- **理由**：CME 的鋼（HRC）合約流動性低、免費即時源不穩；鐵的主要盤在大陸（螺紋鋼/鐵礦石），已涵蓋
- **重新採用的條件**：有需求且找到穩定免費的 HRC/鋼價即時源
